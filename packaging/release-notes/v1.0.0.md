SwiftSpot 1.0.0 is the first release of SwiftSpot: a SwiftUI app for macOS 26 and later, with the Spotify engine from Spotifast inside it.

Install it with Homebrew:

```sh
brew install hanzpo/tap/swiftspot
```

The app is signed with a Developer ID and notarized by Apple.

**Full changelog:** https://github.com/hanzpo/swiftspot/commits/v1.0.0
