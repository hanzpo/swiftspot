SwiftSpot 1.2.1 stops a crash when an audio output goes away, and plays more smoothly when your Mac is busy.

### Fixed

- **Audio outputs.** SwiftSpot no longer quits when a Bluetooth speaker or other output disconnects while it plays.
- **Smoother playback.** The audio thread gets priority and no longer asks for memory while it plays, so the Mac being busy is less likely to cause clicks or gaps.
- **Crash logs.** The log from the previous run is kept after a restart, so a crash leaves a full record behind. The logs are readable only by you.

These fixes come from [fastframe](https://github.com/crmne/fastframe) by Carmine Paolino.

**Full changelog:** https://github.com/hanzpo/swiftspot/compare/v1.2.0...v1.2.1
